# Frontend — React website

React JavaScript/JSX, Vite and Tailwind. Student dashboard, CBT, results and administration are in `src/`.

Install dependencies with `npm ci` from the repository root. From the root, run `npm run dev:frontend` or `npm run build`. Alternatively, run `npm run dev` or `npm run build` inside this folder.

The development API defaults to `http://localhost:4000/api`. The production build uses `/api` unless `VITE_API_URL` is set at build time. See the root README for shared configuration and deployment.
