# Product scope

Only Bihar Board academic preparation: Class 10 and Class 12 Arts/Science/Commerce. No SSC, BPSC, Banking, Railway, jobs or competitive-exam taxonomy.

The initial delivery includes a responsive black/orange React website, a native Expo student app and one Node/MongoDB backend. Approved database content determines available subjects and tests; no chapter list or official question distribution is invented in source code.

Practice, CBT and source-verified board-pattern test configurations share an immutable attempt engine. Objective answers score automatically. Typed descriptive answers use an optional provider with enforced rubrics or a human review queue. Students see provisional scores until required reviews are complete.

Administration currently exposes structured JSON editing for complex questions and tests plus forms for academic structure, roles, import and evaluation. A full visual authoring wizard is future work. Bilingual question text and Hindi/English answer input are supported. The landing and key navigation labels have language toggles; a full app-wide Hindi translation is future work.

The payment feature is an optional one-time 30-day pass; recurring subscriptions, refunds/disputes automation and a pricing-plan manager are future work. Optional storage supports staff-uploaded question images; handwritten answer uploads/OCR and evaluating drawn diagrams are future work. Phone OTP, announcements, automated teacher calibration and production load/restore certification are future work.

Release needs verified subject/session patterns, approved question content, teachers to review rubrics, provider configuration and operational/device checks described in DEPLOYMENT.md. The received master prompt ended during mathematics-specific evaluation requirements; no missing later sections have been assumed complete.
