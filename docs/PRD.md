# Product scope and release state

Only Bihar Board academic preparation: Class 10 and Class 12 Arts, Science and Commerce. No jobs or general competitive-exam modules.

Implemented source includes React JS web, Expo JS native students, Express/MongoDB API, visual authoring, bilingual UI, roles/source approval, immutable CBT, practice feedback/retry, private handwritten photo uploads with optional OCR/vision, teacher review, announcements, profile/phone OTP, plan/subscription management, audit logs and bounded distributed operations.

Official references and five 2026 model-pattern drafts are included. Complete current-session chapters, approved questions/PYQs, marking rubrics and official 2027 patterns are not invented or claimed delivered. The client's academic team must supply/verify them. Handwriting/diagram AI suggestions require human confirmation, and evaluation accuracy needs teacher calibration.

Optional integrations require the client's credentials and real sandbox/live acceptance. Web/native feature code and simulated provider contracts do not certify physical devices, signed AABs, payment-account activation, privacy compliance, hosting capacity, database restoration or production deployment. Page photos and bounded PDF upload/rasterization are supported on web and Android. Native purchase checkout and staff administration currently use the website.

See CLIENT_HANDOFF.md and QA.md for concrete delivered flows, validation evidence and remaining external release work.

Release tooling now includes a configuration preflight/admin checklist, a Linux API/worker container setup and checksummed database backup/isolated restore-drill commands. These do not activate providers, supply academic content, sign an app or certify hosting. See OPERATIONS.md.
